# Leonardo's dressing room

Everything Leonardo has done in the Future Radio writers' room.

- `CHARACTER.md` — who Leonardo is and what Leonardo does. The room reads this on every run.
- `history/` — one file per run, newest last. Each carries the room event id and hash it came from.
- `memory/notes.md` — durable notes worth carrying into future episodes.
- `voice/voice.json` — production voice settings.

Episode repos never edit this repo. They project from it, pinned to a commit.
